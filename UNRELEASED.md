# Unreleased

Changes since the last release. Each fix or feature adds a line here; `scripts/release.sh` turns
this list into the release notes and empties it for the next batch.

- The device boxes on the home screen are the same size now and line up across mouse, keyboard and headset.
- The window can be maximized (button or double-click the title bar), and F11 toggles full screen.
- Home photos are sized to match each other, sit on one floor line with the light right under them, and a device that's off is no longer shown darker.
