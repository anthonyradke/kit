# Unreleased

Changes since the last release. Each fix or feature adds a line here; `scripts/release.sh` turns
this list into the release notes and empties it for the next batch. The notes show as a list in
Settings, so keep each line to one short sentence about what changed for the user.

- Release notes in Settings are now a tidy list.
- The tray icon's dot turns red when a device is low on battery, and the tooltip says which.
- NK65 lights go out when the PC locks, sleeps or turns its displays off, with a switch on the Device page.
- Export your settings to a file from Settings, and import them to restore a backup or add someone else's profiles, macros and presets.
